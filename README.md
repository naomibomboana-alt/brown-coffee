# Brown Coffee — site static

Acesta este un site static, fără server și fără bază de date. Poate fi publicat gratuit pe GitHub Pages, Cloudflare Pages sau Netlify.

## Publicare gratuită pe GitHub Pages
1. Creează un cont pe GitHub.
2. Creează un repository nou, de exemplu `brown-coffee`.
3. Încarcă `index.html`, `styles.css`, `script.js` și folderul `images`.
4. Intră în **Settings → Pages**.
5. La **Build and deployment**, alege **Deploy from a branch**, apoi `main` și `/ (root)`.
6. GitHub va afișa adresa publică a site-ului.

## Fotografii
În această versiune nu am copiat automat fotografii din Google Maps. Cardurile din Galerie sunt pregătite pentru fotografiile oficiale. Dacă ai fotografiile, pune-le în folderul `images` și înlocuiește cardurile din `index.html` cu tag-uri `<img>`.
